# Cheki Gallery · 第一版

> **Deprecated / 已弃用：**这是一份历史设计 artifact，仅供追溯早期方案。内容可能与当前 KanzenCheki 实现不符；请以代码和 [README](../README.md) 为准。

## 界面

以实体收藏品为中心的桌面相册。左侧收藏导航（全部、待整理、人物），中央可调密度的拍立得网格，右侧详情。米白底色、低饱和强调色，使用 daisyUI 组件和 Tailwind 布局，不做统计仪表盘。

详情首先显示拍摄日期、多人标签、备注，然后显示独立影像列表。每次扫描与生活场景都是独立 Asset；展开影像才能看到原件、浏览版和缩略图。列表中的收藏数量只计算 Cheki。

## 关系

- Cheki：一件实体收藏品；可关联多个人物。
- Asset：一次独立成像；通过 ChekiAsset 与 Cheki 多对多关联。返切可以同时关联多张 Cheki，无须复制文件。
- Rendition：属于一个 Asset；标记 original、display、thumbnail。扫描仪压缩版属于同一次扫描的 Rendition，不是新 Asset。
- 人物标签属于 Cheki；文件路径属于 Rendition，不依赖文件名存储人物与日期。

## 导入与存储方向

导入时区分新收藏、已有收藏的新影像、已有影像的文件版本。新收藏进入待整理，用户核对人物和日期后完成整理。未知日期保留为空，不用文件修改时间冒充拍摄日期。

正式图库采用 SQLite 索引与图库目录：originals/<asset-id>/<rendition-id>.<ext>，derivatives/<asset-id>/<rendition-id>.jpg。原始文件名作为元数据保留，导入复制完成后才提交索引，失败清理未提交文件。原件不覆盖；大 TIFF 在 Rust 后台流式复制与生成预览，不经前端 base64 传输。

第一轮先搭建 Tauri + SvelteKit + daisyUI 项目与领域模型，再落地图库导入和 SQLite。移动端缓存策略、局域网同步、裁切和识别不进入本轮。

## 第二轮 UI：照片工作台

移除品牌宣传语、开发进度卡片和中央空状态。暖灰底衬托真实照片；窄导航栏只负责筛选；日期分组和尺寸滑块负责浏览密度。收藏下方仅保留短标题和标签，详细元数据按需展开。

- 单击：选择收藏并打开右侧整理栏。
- 双击 / 空格：深色大图预览，底部胶片条切换。
- 左右箭头：上一张 / 下一张；Escape：关闭预览或详情。
- 支持搜索、喜欢、待整理、标签筛选、日期排序。
- 本地 JPEG / PNG / WebP 可以作为临时预览加入，保留原文件，不冒充正式入库；页面关闭后不持久化。

当前为交互设计原型：网络图片来源在详情与 static/demo/SOURCES.md 中，示例元数据为虚构。此轮使用独立展示模型，不代表 SQLite 和完整 Cheki / Asset / Rendition 管理已接入。正式开发仍遵循前述多对多领域模型。

## 第三轮 UI：整页全览与悬浮聚焦

全览改为连续网格，取消固定侧栏与日期分组。顶部为搜索、全部/喜欢/待整理、标签和月份筛选；底部胶囊工具条控制照片尺寸、标题、排序和导入。主滚动区底部预留工具条空间。

单击收藏打开原生模态 dialog：相册在原位置模糊，照片带阴影浮起；简洁信息卡悬浮在照片右侧，编辑表单按需展开。点击背景、返回按钮或 Escape 关闭，原生 dialog 限定键盘焦点。预留照片周围空间，不添加尚未实现的操作。

聚焦底部的低对比胶片条仅列出当前收藏的影像。左右方向键只在这些影像之间切换；单影像收藏真实显示 1/1，不放其他收藏或伪造扫描版。加号可向当前收藏加入临时关联影像，全部相册的收藏数量不变。封面裁切与完整影像属于同一影像的展示方式，不算两个 Asset。依然是会话内的 UI 原型，未实现正式持久化。

### 沉浸模式微调

移除顶部应用名、固定搜索区和筛选栏。相册从窗口上方直接开始；底部工具条的搜索按钮向上展开半透明搜索/筛选面板，保留收藏数量与筛选生效提示。搜索、标签、月份、喜欢和待整理仍可组合使用。点击照片时收起筛选面板，Escape 也可收起。

### 玻璃材质增强（基线提交之后）

工具条、筛选、提示和收藏信息复用 glass-light / glass-panel；影像胶片条与导入按钮使用 glass-dark。降低底色不透明度，以模糊、适度饱和度和边缘高光形成层次。筛选面板与工具条为独立层，避免嵌套 backdrop-filter 阻断背景取样。图片自身不加滤镜；减少透明度偏好及不支持 backdrop-filter 的环境使用实色降级。

### 顶部悬浮导航（最新确认）

主导航采用统计 / 相册 / 人物三个入口，相册位于中间且为默认路由。三个页面共享半透明、阴影式悬浮导航；统计与人物只保留空白内容区。相册顶部为导航留出空间，底部工具条只在相册显示，照片聚焦使用原生模态层覆盖导航。收藏临时数据改为跨路由会话状态，刷新仍会重置。

资产存储方向已确认：软件管理磁盘目录，照片以普通原始文件存放，元数据和关系入数据库。后端尚未接入，见 backend-proposal.md。
